# ASOS 풍속 예측

이 프로젝트는 ASOS 시간별 관측 자료를 전처리하고, 1시간 뒤 풍속을 예측하는
모델을 학습·평가한 뒤 예측 결과 그래프를 만듭니다.

모든 시각은 한국 표준시(KST) 기준입니다.

## 파일 구성

- `asos_108_2023_2024.csv` — 원본 시간별 기상 관측 자료
- `build_wind_dataset.py` — 원본 자료의 시간 간격을 맞추고 학습용 표를 생성하는 스크립트
- `wind_dataset.csv` — 입력 변수와 1시간 뒤 풍속 정답이 담긴 자료
- `train_wind_regression.py` — 선형회귀와 랜덤포레스트를 학습하고 기준 예측과 비교하는 스크립트
- `predictions.csv` — 2024년 12월의 실제 풍속과 각 방법의 예측값
- `plot_prediction_week.py` — 12월 1~7일 예측 그래프를 만드는 스크립트
- `prediction_week.png` — 생성된 주간 예측 그래프

스크립트는 원본 관측 CSV를 수정하지 않습니다.

## 학습 자료 구성

`wind_dataset.csv`의 각 행은 시각 열 2개, 입력 변수 5개, 정답 열 1개로 구성됩니다.

- `forecast_time` — 예측을 수행하는 시각
- `target_time` — 예측 시각에서 정확히 1시간 뒤의 정답 시각
- `wind_speed_ms`, `temperature_C`, `humidity_pct` — 예측 시각의 풍속·기온·습도
- `wind_speed_ms_1h_before`, `wind_speed_ms_2h_before` — 예측 시각 기준 1시간 전과 2시간 전의 풍속
- `actual_wind_speed_ms` — 정답 시각에 관측된 풍속. 모델 입력에는 포함하지 않습니다.

전처리 스크립트는 누락된 시각을 시간별 시간축에 추가하지만, 측정값을 채우지는
않습니다. 필요한 입력값이나 정답이 비어 있거나 필요한 시각의 관측 행이 없으면
해당 학습 행을 제외합니다. 입력에는 예측 시각의 관측값과 정확히 1시간 전·
2시간 전 관측값이 모두 필요합니다.

## 필요한 패키지

Python 3과 다음 패키지가 필요합니다.

- `scikit-learn`
- `matplotlib` (그래프 생성에만 필요)

## 실행 방법

프로젝트 폴더에서 다음 명령을 실행합니다.

```powershell
python build_wind_dataset.py
python train_wind_regression.py
python plot_prediction_week.py
```

각 스크립트는 프로젝트 폴더에 `wind_dataset.csv`, `predictions.csv`,
`prediction_week.png`를 생성합니다.

## 학습 및 평가 방법

학습 스크립트는 `wind_dataset.csv`를 정답 시각 순으로 정렬하고, 정답 시각이
2023년 1월부터 2024년 11월까지인 행으로 학습합니다. 2024년 12월 정답 행으로
평가하며, 평가 중에는 모델을 다시 학습하지 않습니다.

선형회귀와 랜덤포레스트는 같은 다섯 입력 변수와 학습 행을 사용합니다.
랜덤포레스트 설정은 트리 100개, 최대 깊이 6, 리프당 최소 표본 5개,
난수 시드 42입니다. 두 회귀 모델에서 음수 예측값은 0으로 제한합니다.

기준 예측은 현재 풍속이 1시간 뒤에도 같다고 예측하는 방식입니다. 학습
스크립트는 12월 평가 행 전체에서 기준 예측·선형회귀·랜덤포레스트의
평균절대오차(MAE)를 계산하고, 실제값과 예측값을 `predictions.csv`에 저장합니다.

그래프 스크립트는 동일한 예측 자료에서 정답 시각이 12월 1일 00시부터
12월 7일 23시까지인 행을 그립니다. MAE는 그래프 구간이 아니라 12월 전체
평가 행으로 계산합니다.
